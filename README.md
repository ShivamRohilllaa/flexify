# FlexiPhy Therapy

A modern, responsive (mobile-first) physiotherapy clinic website built with plain HTML, CSS, and JavaScript — no build step or dependencies required.

## Run locally

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080 in your browser. Alternatively, just open `index.html` directly.

## Structure

- `index.html` — all page sections (hero, services, about, process, testimonials, FAQ, booking form, footer)
- `styles.css` — mobile-first stylesheet with tablet (640px) and desktop (1024px) breakpoints
- `script.js` — mobile nav, scroll reveal animations, animated counters, testimonial slider with swipe support, booking form handling
